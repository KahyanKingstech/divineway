Divineway Fengshui ECommerce website

Features
1) Firebase Auth - Google Login
2) ERPNext connection 
- Live shop products (Item)
- Live services (Feng Shui Service)
- Live blog (Blog Post)
- Contact Form (Website Enquiry)
3) Stripe - Sandbox Setup

Workflows
1) Login to website via Google - create customer in erpnext
2) Browse shop and make payment - create sales invoice and payment entry in erpnext
3) Submit contact form - create website enquiry in erpnext
